# ADR-0004: VLMの責任を意味理解と最終確認に限定する

- Status: Accepted
- Date: 2026-08-18

## Context

VLMは物体の意味と画像間対応を扱える一方、応答は非決定論的で、実寸距離や毎フレーム追跡の信頼源にはできない。MODOSEでは復元成功の偽陽性を2%以下に抑えることが最優先である。

## Decision

通常フローのVLM呼び出しをBaseline、Compare、Verifyの3用途に限定する。応答はバージョン付きJSON Schemaで検証し、未知の列挙値、曖昧な対応、不正な構造を拒否する。

VLMへAR座標、実寸距離、毎フレーム追跡、完了閾値、ガイド順序、成功表示の直接決定を任せない。`verified`以外のVerify結果では`REALITY RESTORED`へ遷移しない。

## Consequences

- モデル応答だけではユーザー可視の矢印や成功状態を確定できない。
- 端末内追跡、Embedding、現実座標、Rust状態機械を組み合わせる必要がある。
- モデル更新は設定変更で可能だが、既存Schemaと精度マトリクスへの適合確認を必須とする。

## Reconsider when

責任範囲を広げても偽成功率、端末性能、通信断時挙動を物理E2Eで満たせる証拠が得られ、新ADRで安全条件を定義できる場合に限り再検討する。
