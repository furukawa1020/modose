# ADR-0005: 同一ARセッションのlocal-first設計とする

- Status: Accepted
- Date: 2026-08-18

## Context

保存位置と現在位置はARCoreのAnchorおよび同一セッションの座標系に依存する。アプリ終了後や別端末で同じ座標系を再現することは製品の精度契約に含まれない。また、生画像や物体情報のクラウド永続化は不要なプライバシーリスクを生む。

## Decision

保存から復元完了までを同一ARCoreセッションへ限定する。画像、crop、Embedding、SceneSnapshotはアプリ専用ローカル領域へ保存し、クラウドへは既定で永続化しない。Firestoreには許可された運用メタデータだけを保存する。

VLM解析完了後のガイドは端末内追跡で継続できる。最終確認時に通信できない場合は成功へ遷移せず、最終確認待ちとする。セッション削除ではローカルファイルとDBを同じユースケースで削除し、失敗時はtombstoneから再試行する。

## Consequences

- アプリ終了後、別端末、別セッションからの復元は非対応となる。
- 通信断でも既存ガイドを継続できるが、新規VLM解析と最終成功確認はできない。
- バックアップ、ログ、Firestoreへ画像、物体名、Embeddingを流さない実装検査が必要になる。

## Reconsider when

永続Cloud Anchor等を採用しても位置誤差、削除保証、認可、費用、オフライン挙動を満たせる要件とテストが定義された場合に、新ADRで再検討する。
